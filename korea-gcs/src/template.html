위성 (체크 = 지도 표시)

    통과 예측 · 기준 지상국 (KST)

    AOSLOS길이최대

    AOS = 위성이 지평선 위 5°로 떠올라 교신 시작, LOS = 교신 종료.

    지도 클릭 = 촬영 지점 선택
    ▲ 지상국 · 점선 원 = 교신 가능 범위 · 초록 고리 = 교신 중 · 어두운 면 = 밤 · ● 노랑 = 태양 직하점

    실제 운용 순서: ① 명령 생성 → ② 교신 때 업링크 → ③ 예정 시각에 위성이 촬영해 저장 → ④ 다음 교신 때 다운링크 → ⑤ 수신 데이터 탭에서 확인. 광학은 햇빛이 있어야 하고, SAR은 밤·구름에도 찍는다.

    명령 목록

      텔레메트리 = 위성이 보내는 상태 정보. 교신 중에만 10초마다 새 패킷이 들어온다. 값은 교육용 모의 데이터입니다.

      수신 영상은 지도 데이터와 잡음으로 만든 모의 영상입니다(실제 위성 사진 아님). 해안선 모양과 낮·밤, 구름, 센서 종류의 차이를 보여 줍니다.
